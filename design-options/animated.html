Option E · Canvas ambient

Living Wavefield

The whole window is a multi-layer live waveform field. Metrics float as glass chips on top of the signal — the chart is the product, not a widget inside a card.

  • CPU / mem / net as stacked animated layers
  • Floating metric chips with soft vertical drift
  • AI usage as a pulsing progress filament
  • Menu bar reuses a single micro-sparkline
Motion language Continuous field draw (60fps) · chip float 5s · bar pulse 2.4s · load maps to wave amplitude in real app

Option F · Radial motion

Orbital Rings

Concentric rings orbit at different speeds — each ring is a metric. Arc length encodes utilization; spin rate encodes activity. Center shows the “primary” vital (CPU or user-pinned).

  • 4 rings: CPU, Memory, Network, Battery
  • Breathing core with soft glow
  • Side rail for AI + processes (static data)
  • Great for a square or tall window
Motion language Independent ring rotation · core breathe 3.2s · status dots pulse · in SwiftUI: TimelineView + animatable arc trim

Option G · Instrument / CRT

Signal Scope

Oscilloscope metaphor: phosphor grid, sweeping beam, multi-channel traces with glow decay. Extremely expressive with animation — every sample is a living draw, not a static polyline.

  • Sweeping beam reveals “fresh” data edge
  • Channel strips tick as values update
  • Monospace + green phosphor (or amber mode)
  • Optional phosphor trail persistence
Motion language Beam sweep 2.8s · live multi-trace canvas · value tick flash · SwiftUI: Canvas + TimelineView, or Metal for true phosphor

Option H · Soft organic

Breathing Cells

Light, friendly, and alive. Bento cells with soft color blobs that morph and drift — utilization is felt as visual energy, not just a number. Live sparkline sits inside the large CPU cell.

  • Bento grid (1 large + 4 small)
  • Gaussian blobs scale with activity
  • Light-first; dark = ink + muted glow
  • Warm paper surface, rounded 18px
Motion language Blob morph 5–8s · live wave in hero cell · spring on range change · SwiftUI: matchedGeometry + blur circles + TimelineView sparkline

Option I · Number as motion

Kinetic Counters

The numbers themselves animate — odometer-style digit rolls on every sample, with live drawing sparklines and a scanning accent line. Minimal layout; motion is the hierarchy.

  • 6 equal cards, monochrome chrome
  • Digit strips roll with spring easing
  • Per-card live sparkline (color-coded)
  • Scan-line accent on update
Motion language Digit roll cubic-bezier · sparkline scroll · scanline on tick · SwiftUI: contentTransition(.numericText) + phaseAnimator
