Data-driven motion

Practical rule: every animation encodes a real metric. Nothing loops “for vibe.” Drag the controls below — all mockups share the same live sample state, so you can see how motion should respond to idle, load, memory pressure, network bursts, and charging.

Particle Flow Spark Strip Bound Orbital Activity Field Filled Meters Motion contract A–D layouts

1. History draws the line

Sparklines and charts are append-only samples over time — not decorative noise generators.

2. Level sets amplitude

Ring arcs, bar fills, blob size, and core glow scale with the current value (0–100% or rate).

3. Delta sets urgency

Only animate transitions when the value changes. Idle ≈ still. Spike ≈ brief motion, then settle.

4. No fake activity

If GPU load is unavailable, don’t animate a GPU wave. Flat / “Detected” is the honest state.

Motion contract for Vitals

Use this as the rule set when implementing any of the layouts (A–D) or motion skins (strip / rings / field / meters / particles).

Channel Must bind to Do Don’t
Sparkline / chart path History arrays (cpuValues(), etc.) Append sample each poll; draw only real points Math.sin loops, Perlin ambient, “alive” noise
Bar / ring arc length Current fraction or rate/peak Ease width/arc to new value on sample Indeterminate progress spinners for known levels
Spin / pulse rate |Δvalue| or rate magnitude Near-zero motion when idle; faster when changing Constant 12s rotation regardless of load
Number transitions Last sample vs previous numericText only when value changes Odometer rolling forever
Color intensity / glow Level vs thresholds (warn / critical) Escalate at your alert thresholds Rainbow cycling, random hue shift
GPU / NPU visuals Availability only (today) Static “Detected” / flat line Fake utilization waveforms
AI token bar Tokens today / sessions Width from measured tokens; update on scan Shimmer while idle between scans
Particle Flow field 3 bar charts from history · height 0–100% · bat dims One bar per sample slot; L=old R=now Decorative particles / random gaps
